# Preconditions
- The robot has reached the step limit without completing the task.
- The robot has repeatedly picked up incorrect items.
- No human briefing or corrective instruction has been received.

# Steps
1. Stop attempting the current task.
2. Avoid repeating the same failed actions.
3. Identify failure class (e.g., search-exhaustion, object-confusion, retook-from-destination).
4. Reassess the task goal and available objects.
5. Request assistance or re-evaluation from a human.

# Pitfalls
- Continuing to repeat the same failed actions without re-evaluation.
- Failing to recognize the failure class and respond appropriately.

# Not established
- The exact cause of failure in cases where multiple failure classes overlap.
- Whether the robot can recover autonomously without human intervention.
