# Preconditions
- The target object must be located in a receptacle that can be accessed without excessive searching.
- The robot must be aware of the correct tool or action required to complete the task (e.g., cleaning, heating, or cooling).

# Steps
1. Take the target object from its current location.
2. Perform any required transformation (e.g., clean, heat, or cool) using the appropriate tool.
3. Move the object to the destination receptacle.
4. Confirm that the object has been successfully placed and the task is complete.

# Pitfalls
- Searching for the object in the wrong location or checking too many receptacles before finding it.
- Picking up the wrong object and moving it unnecessarily.
- Failing to perform the required transformation before placing the object.

# Not established
- Whether the robot can reliably distinguish between similar objects (e.g., apple and tomato) without explicit naming or briefing.
- Whether the robot can consistently identify the correct receptacle for the object without prior knowledge or guidance.
