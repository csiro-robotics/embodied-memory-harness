# Preconditions
- The robot has prior knowledge of where the object is likely to be found.
- The object has not been previously located in the current search area.

# Steps
1. Start by checking the most likely receptacles based on prior knowledge of the object's usual location.
2. Search each receptacle systematically, moving to the next one if the object is not found.
3. Stop searching if the object is found and move it to the target location.
4. If the object is not found after checking a reasonable number of receptacles, stop searching and seek clarification from the user.

# Pitfalls
- The object may have been moved from its usual location.
- The robot may confuse similar-looking objects.
- The robot may not know the object's usual location, leading to inefficient searches.

# Not established
- Whether the object is still in its usual location.
- Whether the robot can reliably distinguish between similar objects without visual confirmation.
- The exact number of receptacles that constitutes a "reasonable" number for stopping the search.
