# Preconditions
- The target object must be located in a receptacle that has been checked.
- The destination must be a valid receptacle.
- The robot must verify the identity of the object before and after movement to avoid confusion with visually similar items.
- The object must not already be in the destination receptacle.

# Steps
1. take <obj> from <place>
2. verify <obj> with <tool>
3. move <obj> to <destination>
4. verify <obj> with <tool>

# Pitfalls
- Searching multiple receptacles without finding the object may lead to failure.
- Picking up the wrong object can cause confusion and delay the task.
- The robot may attempt to move objects that are not the target, leading to task failure and wasted steps.
- Re-picking the object from the destination after it has already been placed can lead to step exhaustion and task failure.
- If the object is not found in any receptacle, the task may fail due to search exhaustion.
- Repeatedly moving the object between the same locations can lead to task failure.

# Not established
- Whether the object must be verified explicitly after being taken, or if verification is implicit in the action of taking it.
- Whether the robot should attempt to search multiple receptacles if the object is not found in the first one.
