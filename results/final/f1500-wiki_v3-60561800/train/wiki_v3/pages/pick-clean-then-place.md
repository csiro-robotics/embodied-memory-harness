# Preconditions
- The target object must be located in a receptacle that has been checked.
- The object must be correctly identified to avoid confusion with similar items.
- If the target object is not found during the initial search, avoid picking up and cleaning visually similar items unless explicitly instructed.

# Steps
1. take <obj> from <place>
2. clean <obj> with <tool>
3. move <obj> to <receptacle>

# Pitfalls
- Confusing the target object with similar-looking items (e.g., soapbar with soapbottle).
- Retaking the object from the destination receptacle after it has already been placed.
- Failing to issue a transformation command (e.g., cleaning) before moving the object.
- Picking up visually similar objects from the same receptacle before cleaning the target object.

# Not established
- Whether the robot can reliably distinguish between similar objects in all lighting and clutter conditions.
- Whether the robot can consistently find the target object without exhaustive searching.
- Whether the robot can avoid repeatedly retaking the object from the destination receptacle after it has been placed.
- Whether the robot can reliably issue a cleaning command when the object is already in the correct location.
