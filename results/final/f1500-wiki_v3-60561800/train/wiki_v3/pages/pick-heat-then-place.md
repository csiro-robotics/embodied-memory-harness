# Preconditions
- The target object must be located in a receptacle that has been checked.
- The object must be identifiable and not confused with similar items.
- The fridge should be checked first, as it is a common location for raw or unheated items.

# Steps
1. take <obj> from <place>
2. move <obj> to <heating appliance>
3. heat <obj> with <tool>
4. move <obj> to <receptacle>

# Pitfalls
- Confusing the target object with similar-looking items (e.g., picking up a mug instead of a cup).
- Failing to locate the target object, leading to search exhaustion.
- Attempting to heat an object that is not the target, or not applying the heat transformation correctly.
- Picking up unrelated items from the same area, which leads to confusion and task failure.

# Not established
- Whether the object is already at the correct temperature before heating.
- Whether the receptacle where the object is placed is suitable for the heated object.
- Whether the tool used for heating is appropriate for the object type.
- Whether the destination receptacle has already been checked before placing the object.
- Whether the object needs to be cooled or cleaned before or after heating.
- Whether the object is already in the correct location and does not need to be moved.
