# Preconditions
- The robot is searching for an object and encounters visually similar items.

# Steps
1. Pause and inspect the object visually to confirm its identity.
2. Compare the object with known examples of similar-looking items.
3. If uncertain, delay handling the object and seek clarification.
4. Use descriptive language to distinguish the object from others (e.g., "the red remotecontrol" or "the small potato").
5. Only proceed with handling the object once its identity is confirmed.

# Pitfalls
- Assuming an object is the target based on appearance alone.
- Failing to compare with similar items, leading to incorrect handling.
- Proceeding without verification, which may result in failure or incorrect task completion.
