# Preconditions
- The target object must be identified and located in the environment.
- The cooling tool (e.g., fridge) must be accessible and available for use.
- The destination must be distinct from the object's current location to avoid unnecessary movement.

# Steps
1. Identify the target object and confirm its location.
2. Take the target object from its current location.
3. Cool the object with the fridge.
4. Move the cooled object to the designated destination.

# Pitfalls
- Confusing the target object with visually similar items (e.g., potato with pot, apple with bread).
- Picking up visually similar objects from the same receptacle before cooling the target object.
- Picking up the wrong object and attempting to cool it, leading to failure.
- Failing to move the cooled object to the correct destination.
- Attempting to cool an object that is already in the destination location, leading to confusion and unnecessary movement.

# Not established
- Whether the cooling process is successful in all cases.
- Whether the destination is always accessible or requires additional steps.
- Whether the robot can distinguish between similar objects without explicit labeling.
- Whether the target object is always found in the fridge or other receptacles, as evidence shows it may be located elsewhere.
- Whether the robot can reliably locate the target object in all cases, as some episodes show failure to find the object despite checking multiple receptacles.
