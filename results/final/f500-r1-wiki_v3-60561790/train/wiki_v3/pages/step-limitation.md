# Preconditions
- The robot is performing a task that involves object identification, transformation, or search.
- The robot is approaching or has exceeded the step limit.

# Steps
1. Identify the target object and its location.
2. Take the target object from its location.
3. Move the target object directly to the destination without unnecessary intermediate steps.
4. Avoid picking up and moving non-target objects.
5. Confirm the task is complete before ending the episode.

# Pitfalls
- Picking up non-target objects leads to wasted steps and confusion.
- Repeatedly moving the same object between locations without progress increases step count.

# Not established
- Whether the robot can distinguish between similar objects without additional sensory input.
