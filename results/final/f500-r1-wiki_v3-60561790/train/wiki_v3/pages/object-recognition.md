# Preconditions
- The robot must be attempting to pick up or place an object.
- The object must be in a receptacle or on a surface.

# Steps
1. take <obj> from <place>
2. verify <obj> is the target object
3. if <obj> is not the target, recheck <place> for the correct object
4. move <obj> to <place>

# Pitfalls
- The robot may pick up an object that looks similar to the target but is not it.
- The robot may fail to recognize the target object even when it is clearly visible.
- The robot may repeatedly pick up incorrect objects, leading to wasted steps and failure.

# Not established
- Whether the robot can distinguish objects based on texture or shape.
- Whether the robot can recognize objects in low-light conditions.
- Whether the robot can reliably distinguish between objects with similar names or appearances.
- Whether the robot can avoid picking up visually similar objects when the target is not present.
- Whether the robot can recognize objects that are partially obscured or in complex environments.
- Whether the robot can distinguish between objects that are in the same receptacle or on the same surface.
