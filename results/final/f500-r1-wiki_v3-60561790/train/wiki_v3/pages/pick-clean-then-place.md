# Preconditions
- The object to be cleaned must be located in a receptacle.
- The cleaning tool (e.g., sinkbasin) must be accessible.

# Steps
1. Identify the target object by name and ensure it is the correct item.
2. Take the target object from its receptacle.
3. Move the object to a suitable location for cleaning.
4. Clean the object with the appropriate tool (e.g., sinkbasin).
5. Move the cleaned object to the designated receptacle.

# Pitfalls
- Picking up the wrong object may lead to failure.
- Failing to clean the object before placing it may result in incorrect task completion.
- Repeatedly taking the object from the destination receptacle without completing the task can cause infinite loops.

# Not established
- The exact number of receptacles to check before finding the target object.
- Whether the object is already clean and does not require cleaning.
- The specific tool to use for cleaning in all cases.
