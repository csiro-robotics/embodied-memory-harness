# Preconditions
- The room has a desklamp, often on a different receptacle from the object.

# Steps
1. Find <obj> and take <obj> from <place>
2. Keep <obj> in hand and go to the receptacle that holds the desklamp
3. Use desklamp while holding <obj>

# Pitfalls
- A move command puts <obj> down, so the lamp must be used before <obj> is put anywhere.
- Examining <obj> away from the desklamp does not complete the task.

# Not established
- Which receptacle holds the desklamp in a new room, so it must be found by looking.
