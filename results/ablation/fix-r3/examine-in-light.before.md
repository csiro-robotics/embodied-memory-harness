# Preconditions
- The object to be examined is already in a location with access to light.

# Steps
1. Use desklamp
2. Take <obj> from <place>
3. Move <obj> to <place> if necessary to position under the desklamp
4. Examine <obj> with desklamp

# Pitfalls
- Moving the object unnecessarily may lead to confusion and failure.
- Failing to use the desklamp before examining the object may result in incomplete or incorrect examination.

# Not established
- The exact conditions under which an object is already in a suitable location for examination.
- The optimal placement of the object relative to the desklamp for best results.
